# STOA v0.1.0 - Version MVP

Nous sommes ravis d'annoncer la première version publique de STOA Platform !

<!-- truncate -->

## Points forts

### MCP Gateway

- Support du Model Context Protocol (MCP)
- Authentification sécurisée des agents IA via clés API
- Moteur de politiques OPA pour un contrôle d'accès granulaire
- Routage des requêtes vers les serveurs MCP

### Control Plane

- API Core basée sur Python/FastAPI
- Architecture multi-tenant
- Gestion des abonnements et des clés API
- GitLab comme source de vérité (GitOps)

### Portail Développeur

- Catalogue d'APIs/outils en libre-service
- Gestion des abonnements
- Tableaux de bord d'utilisation
- Documentation interactive

### Console d'administration

- Gestion des tenants
- Administration des utilisateurs
- Configuration des politiques
- Visualiseur des journaux d'audit

### Sécurité

- Intégration SSO Keycloak (OIDC/OAuth2)
- HashiCorp Vault pour la gestion des secrets
- RBAC avec 6 personas et 12 scopes
- Support mTLS pour les services internes

### Infrastructure

- Déploiement natif Kubernetes
- Charts Helm disponibles
- Compatible ArgoCD GitOps
- Observabilité Prometheus/Grafana

## Changements majeurs

Aucun — il s'agit de la première version !

## Problèmes connus

- [ ] La limitation de débit n'est pas encore implémentée (à venir dans v0.2.0)
- [ ] La mesure d'utilisation est en bêta
