# STOA v2.2.0

La plus grande version de STOA à ce jour — 1 091 commits, 297 fonctionnalités et un virage fondamental vers la gestion d'API AI-native.

<!-- truncate -->

## Points forts

### Proxy LLM et gestion des coûts

- Routage LLM multi-fournisseurs (OpenAI, Azure OpenAI, Mistral) avec sélection de namespace tenant-aware
- Suivi des budgets par tenant avec mise en application et circuit breakers
- Suivi des tokens de cache Anthropic pour l'optimisation des coûts
- Dashboard Grafana dédié au suivi des tokens LLM

### Inscription en libre-service

- Flux de provisionnement de tenant de bout en bout : page d'inscription au portal, endpoint de provisionnement API, mise en application des limites d'essai
- Automatisation des tenants de démonstration pour l'onboarding
- Données d'amorçage pour l'API Chat Completions avec 2 plans de souscription

### Protocole MCP 2025-11-25

- Protocole mis à niveau avec resources, prompts et endpoints REST de complétion
- Découverte MCP lazy avec pattern cache-first
- Validation du schéma des outils à l'enregistrement
- Méthodes de conformité à la spec MCP

### Durcissement OAuth 2.1

- Liaison DPoP proof-of-possession (middleware sender-constraint)
- Endpoints de gestion DCR RFC 7592
- Durcissement du proxy avec circuit breaker + retry pour les appels OAuth et Control Plane

### Système de Skills

- CRUD de skills natif au Gateway avec suivi de santé via circuit breaker
- Intégration de la découverte MCP lazy
- Validation du schéma des outils à l'enregistrement

### UAC (Universal API Contract)

- Bibliothèque de validation JSON Schema v1.0
- Transformation inverse OpenAPI avec tests de conversion aller-retour
- Types de contrat LLM pour le binding UAC

## Control Plane API (Python/FastAPI)

12 nouveaux endpoints :

| Méthode | Chemin | Description |
|--------|------|-------------|
| `POST` | `/v1/tenants/provision` | Provisionnement de tenant en libre-service |
| `POST` | `/v1/tenants/export` | Export de tenant pour la reprise après sinistre |
| `POST` | `/v1/tenants/import` | Import/restauration de tenant |
| `GET/POST` | `/v1/billing/budgets` | Service de budget LLM + config fournisseur |
| `GET/POST` | `/v1/billing/consumers` | CRUD des consommateurs de facturation |
| `GET/POST` | `/v1/billing/models` | Modèles de facturation + vérification du budget |
| `GET/POST` | `/v1/contracts` | Gestion du cycle de vie des contrats |
| `GET/POST` | `/v1/data-governance` | Endpoints de gouvernance des données |
| `GET/POST` | `/v1/pii` | Middleware de masquage PII + endpoints d'administration |
| `GET` | `/v1/security/posture` | Scanner de posture de sécurité |
| `GET` | `/v1/system/info` | Informations système avec édition/licence |
| `POST` | `/v1/signup` | Inscription en libre-service |

## Guide de mise à niveau

```bash
# Mise à niveau Helm
helm repo update stoa
helm upgrade stoa-platform stoa/stoa-platform -n stoa-system

# Vérification
kubectl get pods -n stoa-system
curl https://api.<YOUR_DOMAIN>/health
```

Pour une vérification détaillée de la mise à niveau, consultez le [script de vérification de mise à niveau](https://github.com/stoa-platform/stoa/blob/main/scripts/release/verify-upgrade.sh).
