:::tip Configurer votre environnement
Les exemples ci-dessous utilisent des variables d'environnement. Définissez-les pour votre instance STOA :

```bash
export STOA_API_URL="https://api.<YOUR_DOMAIN>"    # API du Control Plane
export STOA_AUTH_URL="https://auth.<YOUR_DOMAIN>"   # Fournisseur OIDC Keycloak
export STOA_GATEWAY_URL="https://mcp.<YOUR_DOMAIN>" # Endpoint MCP Gateway
```

Remplacez `<YOUR_DOMAIN>` par le domaine de votre instance STOA.
:::
