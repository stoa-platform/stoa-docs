# Tutoriels

Des tutoriels pas-à-pas, orientés résultat. Chacun vous emmène de zéro à un résultat fonctionnel.

:::tip Vous cherchez la documentation de référence ?
Les tutoriels vous apprennent à **atteindre un objectif**. Pour les options de configuration détaillées, consultez les [Guides](/docs/guides/quickstart) et la [Référence](/docs/reference/configuration).
:::

## Pour commencer

| Tutoriel | Durée | Ce que vous construirez |
|----------|-------|------------------------|
| [Exposer une API REST comme outil MCP](/docs/tutorials/expose-rest-as-mcp) | 10 min | Une API REST appelable par les agents IA via MCP |
| [Souscription API en libre-service](/docs/tutorials/self-service-subscription) | 5 min | Libre-service développeur avec provisionnement automatique de clés |
| [Pont Oracle OAM via Keycloak](/docs/tutorials/bridge-oracle-oam) | 15 min | Échange de tokens (RFC 8693) d'OAM legacy vers OIDC |

## Prérequis

Tous les tutoriels supposent :
- Une instance STOA Platform (cloud sur `console.gostoa.dev` ou [auto-hébergée](/docs/deployment/hybrid))
- Un navigateur et un terminal
- Des connaissances basiques en API REST et JSON
