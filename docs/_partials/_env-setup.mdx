:::tip Configure your environment
The examples below use environment variables. Set them for your STOA instance:

```bash
export STOA_API_URL="https://api.<YOUR_DOMAIN>"    # Control Plane API
export STOA_AUTH_URL="https://auth.<YOUR_DOMAIN>"   # Keycloak OIDC provider
export STOA_GATEWAY_URL="https://mcp.<YOUR_DOMAIN>" # MCP Gateway endpoint
```

Replace `<YOUR_DOMAIN>` with the domain of your STOA instance.
:::
