# Tutorials

Step-by-step, result-oriented tutorials. Each one takes you from zero to a working outcome.

:::tip Looking for reference docs?
Tutorials teach you how to **accomplish a goal**. For detailed configuration options, see [Guides](/docs/guides/quickstart) and [Reference](/docs/reference/configuration).
:::

## Getting Started

| Tutorial | Time | What You'll Build |
|----------|------|-------------------|
| [Expose a REST API as an MCP Tool](/docs/tutorials/expose-rest-as-mcp) | 10 min | A REST API callable by AI agents via MCP |
| [Self-Service API Subscription](/docs/tutorials/self-service-subscription) | 5 min | Developer self-service with automatic key provisioning |
| [Bridge Oracle OAM Tokens via Keycloak](/docs/tutorials/bridge-oracle-oam) | 15 min | Token exchange (RFC 8693) from legacy OAM to OIDC |

## Prerequisites

All tutorials assume:
- A STOA Platform instance (cloud at `console.gostoa.dev` or [self-hosted](/docs/deployment/hybrid))
- A browser and a terminal
- Basic familiarity with REST APIs and JSON
