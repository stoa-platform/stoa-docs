# Migration from Kong OSS / Enterprise

:::info Coming Soon
This migration guide is under development and will be available in **Q2 2026**.
:::

## Overview

Kong is a popular open-source API gateway. STOA provides a migration path that preserves your existing Kong configurations while adding enterprise control plane capabilities.

## What to Expect

| Kong Feature | STOA Equivalent |
|--------------|-----------------|
| Services & Routes | API Catalog |
| Plugins | STOA Policies |
| Consumers | Subscriptions |
| Rate Limiting | Native support |
| Authentication | Keycloak integration |

## Migration Complexity

**Estimated complexity:** Low  
**Estimated timeline:** 2-4 weeks

Kong's declarative configuration model maps well to STOA's GitOps approach.
