# Migration from Google Apigee

:::info Coming Soon
This migration guide is under development and will be available in **Q2 2026**.
:::

## Overview

Apigee is Google Cloud's API management platform. STOA provides a hybrid alternative for organizations seeking European sovereignty or multi-cloud flexibility.

## What to Expect

| Apigee Feature | STOA Equivalent |
|----------------|-----------------|
| API Proxies | API Routes |
| Products | API Groups |
| Apps | Subscriptions |
| Analytics | Grafana dashboards |
| Developer Portal | STOA Portal |

## Migration Complexity

**Estimated complexity:** Medium (varies based on implementation)
**Estimated timeline:** 4-6 weeks typical (depends on API count and customizations)

Apigee's policy model requires translation to STOA's format.

## Why Migrate from Apigee?

- **Data Sovereignty** — Keep data in EU with hybrid deployment
- **Cost Control** — Open-source core, no per-call pricing
- **Multi-Cloud** — Avoid Google Cloud lock-in
- **Compliance** — DORA/NIS2 ready architecture
